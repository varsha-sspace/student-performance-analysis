# Student Performance Analysis 📊

## About the Project
This is my first Data Science project. I analysed the academic performance of five students using Python.

## Tools & Libraries Used
- Python
- NumPy
- Pandas
- Matplotlib
- Google Colab

## Project Objectives
- Calculate individual student averages.
- Analyse subject-wise performance.
- Identify the class topper.
- Calculate pass percentage.
- Visualise student performance using graphs.

## Key Findings
- Total students: 5
- Class average: 82.33
- Pass percentage: 100%
- All students passed.

## What I Learned
- Working with NumPy arrays.
- Creating DataFrames using Pandas.
- Performing data analysis.
- Creating bar charts and pie charts.
